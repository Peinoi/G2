# 후원 파트 개요
```
본 프로젝트의 후원 시스템은 장애인을 위한 지원 프로그램 운영을 목적으로,
사용자가 쉽고 안전하게 기부에 참여할 수 있도록 설계된 모듈입니다.
후원자는 후원 프로그램과 금액을 선택하여 결제할 수 있으며, 후원 내역과 후원 활동보고서는 시스템에 기록되어 관리됩니다.
```
